# RodzEdu

RodzEdu is a radiology continuing-education marketplace. See `README.md` for the
feature list, tech stack, scripts, and env vars. This file captures non-obvious
context for working in this codebase.

## Architecture notes

- Single Next.js 16 App Router app (no monorepo). Server Components + Server Actions do the data work; there is no separate API service.
- Auth is custom: `lib/session.ts` signs a JWT (`jose`) into an httpOnly cookie; `getCurrentUser()` reads it. Server Actions in `app/actions/*` guard access. Roles are `STUDENT` / `TEACHER` (stored as strings because SQLite has no enums).
- Data access goes through the Prisma singleton in `lib/db.ts`.

## Cursor Cloud specific instructions

- Node 20.9+ is required (this repo was built and tested on Node 22). Package manager is **pnpm**.
- **Prisma 7 uses a driver adapter, not a connection URL.** The client is created with `new PrismaClient({ adapter: new PrismaBetterSqlite3({ url }) })` (note the capitalization: `PrismaBetterSqlite3`). Do not pass `datasources`/`datasourceUrl` — Prisma 7 rejects them.
- The **generated Prisma client lives at `lib/generated/prisma/`** (import from `@/lib/generated/prisma/client`) and is gitignored. It is regenerated by the `postinstall` script (`prisma generate`), so a fresh `pnpm install` is enough; if types look stale, run `pnpm db:generate`.
- Local DB is SQLite at `prisma/dev.db` (gitignored). A fresh checkout has **no database file** — run `pnpm db:push` then `pnpm db:seed` to create the schema. The update script only runs `pnpm install` (which regenerates the client), so run these DB steps yourself when the file is missing.
- **The catalog is intentionally seeded empty** — `pnpm db:seed` only creates two demo login accounts (`teacher@rodzedu.com` / `student@rodzedu.com`, password `password123`); instructors publish courses from the studio. Do not re-add seeded courses unless asked.
- Prisma 7 blocks `prisma db push --force-reset` (used by `pnpm db:reset`) without an explicit consent env var. For a clean wipe of the local dev DB, stop the dev server and delete `prisma/dev.db*`, then `pnpm db:push` + `pnpm db:seed`.
- The app is designed to **run with zero env config** (dev defaults for `DATABASE_URL`, `AUTH_SECRET`). `.env` is gitignored; copy `.env.example` if you want to customize.
- **Stripe is optional.** With no `STRIPE_SECRET_KEY`, enrollment (including paid courses) falls back to an instant demo enrollment so the full flow is testable without keys. To test real Checkout, set `STRIPE_SECRET_KEY` (+ `STRIPE_WEBHOOK_SECRET` for the webhook at `/api/stripe/webhook`).
- Next.js 16 runs on **Turbopack by default**; `pnpm dev` writes to `.next/dev` and `pnpm build` writes to `.next`, so dev and build can run concurrently.
- Standard commands (dev/build/lint/db) are documented in `README.md` — use those rather than duplicating here.
